# 本地文档知识库桌面助手

## 前端功能介绍：文档原文阅读、侧栏文件树与原文保存

> 文档性质：前端功能与交互设计说明  
> 目标：在不改变现有后端、向量检索和问答逻辑的前提下，优化桌面端信息架构，让用户能够像使用 Obsidian 一样管理并直接阅读上传的原始文档。  
> 状态：需求确认稿，暂不改代码。

---

## 1. 功能目标

当前版本的主要操作入口是“文档表格”和“对话页”，文档更像“被上传后的管理对象”，阅读体验不够直接。新版本希望把产品重心从“文件管理”转移到“阅读 + 问答 + 整理”一体化：

1. 上传文档后，文件立即出现在当前知识库侧栏中，形成可浏览、可搜索、可拖拽的文件树。
2. 单击任意文件即可在主工作区直接阅读原文，无需切换到外部软件。
3. 阅读状态自动保存，例如当前打开的文件、页码、缩放比例和滚动位置。
4. 当 AI 回答引用某份资料时，可以点击引用跳转到原文对应页并高亮相关段落。
5. 用户可随时保存、导出原文副本，或把对话/生成内容保存为 Markdown 文档并加入当前知识库。

---

## 2. 信息架构与页面布局

新界面参考 Obsidian 的“侧栏 + 主工作区 + 可切换上下文”结构，取消当前把文档做成中心表格的固定感。

```text
┌──────┬──────────────────┬───────────────────────────────────────┬──────────┐
│      │  知识库文件侧栏    │          主工作区                     │ 出处侧栏   │
│ 导航  │                  │                                       │（可折叠）  │
│ 图标  │ 当前知识库        │  ┌──────────── 文档标签页 ──────────┐  │ 引用来源  │
│      │ ├─ 文档目录       │  │ 标题栏 / 页面工具 / 原文操作       │  │ 当前文件  │
│      │ │  PDF           │  │                                   │  │ 页码      │
│      │ │  Word/PPT      │  │       文档阅读区域                 │  │ 检索片段  │
│      │ │  Markdown      │  │                                   │  │ OCR 图片  │
│      │ │  图片          │  └───────────────────────────────────┘  │          │
│      │ ├─ 会话          │                                       │          │
│      │ └─ 最近打开      │                                       │          │
└──────┴──────────────────┴───────────────────────────────────────┴──────────┘
```

### 2.1 最左侧导航栏（推荐宽度 40~56px）

- 仅放置高频全局图标，例如“知识库”“全局搜索”“对话”“设置”。
- 图标悬停时显示文字提示，导航栏支持隐藏，整体视觉接近 Obsidian。
- 不在导航栏放置长文字按钮，避免拥挤。

### 2.2 知识库与文件侧栏（推荐宽度 260~340px）

这是本次新增能力的核心区域，替代当前右侧“文档表格”作为主要文件入口：

- 顶部显示当前知识库名称，并允许快速切换知识库。
- 侧栏分为可折叠分区：
  - `文档`：展示当前知识库中的原始文件。
  - `生成内容`：展示由对话生成的 Markdown。
  - `最近打开`：展示最近阅读的文件，支持恢复阅读位置。
  - `会话`：展示当前知识库的历史会话。
- 文档支持按类型自动分组：PDF、Word/PPT、Markdown/TXT、图片。
- 支持“列表视图”和“分组视图”切换；视图选择与滚动位置可持久化。
- 支持在侧栏顶部输入关键词过滤文件。
- 上传文件后，文件项以“处理中 → 成功/失败”状态即时刷新。

#### 2.2.1 文件项设计

每个文件项建议包含：

- 文件类型图标，PDF、DOCX、PPTX、Markdown、TXT、图片分别使用不同识别色。
- 文件名，过长时省略号结尾，悬停显示完整名称。
- 右侧弱化显示状态图标或数字角标，例如处理失败时显示红色感叹号。
- 选中态使用“左侧竖线 + 浅色底色”，不使用高饱和卡片背景。
- 右键菜单包含：打开原文、在文件夹中显示、重新处理、复制路径、重命名、另存为、删除。

### 2.3 主工作区

主工作区采用“多标签页 + 阅读器/编辑器”结构：

- 打开新文件时新增标签页，标签页之间可拖拽排序。
- 标签页默认显示文档名；当前阅读位置不同时显示弱化圆点。
- 关闭应用后重启，可恢复上次打开的标签页与阅读位置。

### 2.4 可折叠出处侧栏（可选）

- 当用户从 AI 回答跳转到原文时，右侧显示当前片段所属文档、页码、图号、OCR 文本和检索元信息。
- 平时可完全隐藏，避免阅读区域被压缩。

## 3. 文档原文阅读器

### 3.1 支持范围

| 文件类型 | 阅读方式 | 说明 |
| --- | --- | --- |
| PDF | 原生阅读器 | 连续滚动、翻页、缩放、文字选择、搜索、页码定位 |
| Markdown / TXT | 阅读/编辑模式 | 类似 Obsidian 的渲染预览与源码编辑，支持自动保存 |
| DOCX | 原文阅读 | 优先展示版式化正文，必要时提供“外部打开原文” |
| PPTX | 原文阅读 | 按页展示幻灯片文字与图片，支持上一页/下一页 |
| 图片 | 图片查看器 | 大图缩放、旋转、查看 OCR 结果 |
| 其他格式 | 打开方式引导 | 提示在系统中使用关联软件打开 |

### 3.2 阅读工具栏

阅读器顶部提供轻量工具区：

- 左：面包屑或当前文件所在知识库路径。
- 中：页数、页码输入、缩放比例、适应宽度/适应整页。
- 右：全文搜索、全屏、在文件夹中显示、另存为、外部打开。

PDF 阅读体验应接近主流阅读器：

- 支持单页/连续页切换。
- 保留每页文字可选。
- 搜索词在正文中高亮，并显示命中页码。
- 从 AI 引用跳转后，自动打开对应 PDF 并滚动到目标页。

### 3.3 阅读状态自动保存

- 自动保存当前知识库、当前文件、标签页顺序、PDF 页码、滚动位置、缩放比例。
- 重启后可一键恢复。
- 阅读状态仅属于 UI 层，不改变原文文件，不影响向量索引。

## 4. 保存与导出功能

### 4.1 原文保存/另存为

- 用户在阅读器中点击“另存为”，可将原始文件保存为所选目录下的副本。
- 保存时保留原文件名和扩展名；同名文件出现前弹出覆盖确认。
- 保存完成后提示“打开所在文件夹”或“再次保存”。
- 原始文档在应用数据目录中仍保持完整副本，可用于备份和迁移。

### 4.2 阅读中的 Markdown 自动保存

- 对于 Markdown 和 TXT，阅读器提供“阅读/编辑”双模式。
- 编辑器自动保存，或按 Ctrl+S 手动保存。
- 保存后同步更新 SQLite 中的文件修改时间，并提示用户可选择重新向量化。

### 4.3 对话生成内容保存

- 对话记录、AI 生成文档可保存到指定目录。
- 可选择保存后自动加入当前知识库，并在侧栏“生成内容”分区中显示。
- 生成的 Markdown 可再次打开，在阅读/编辑双模式中继续修改并保存。

---

## 5. 阅读与问答联动

1. AI 回答中的引用来源显示为可点击标签，例如“课件.pdf 第12页”。
2. 点击后主工作区打开对应原文，并自动滚动到第 12 页。
3. 若引用来自图片，则打开对应图片并展示 OCR 文本或视觉描述。
4. 阅读器中选中一段文本后，可点击“提问选中内容”或“复制为引用”。

---

## 6. 状态与异常处理

| 状态 | 用户反馈 |
| --- | --- |
| 空知识库 | 侧栏显示引导文案“拖拽文档到此处或点击上传” |
| 文件处理中 | 侧栏显示进度，阅读器保持可用 |
| 文件处理失败 | 文件项显示错误图标，点击可查看原因并重新处理 |
| 文件缺失 | 阅读器显示“原文件已移动或删除”，可定位外部路径 |
| 不支持的格式 | 阅读器给出明确说明，并提供“在外部程序中打开” |
| 大文件 | PDF 分页加载，先显示前若干页，不阻塞界面 |
| 原文已修改 | 提示重新处理以更新向量索引 |

---

## 7. 视觉与交互要求

- 整体采用接近 Obsidian 的“低装饰”布局：平面侧栏、细分割线、轻微悬停反馈。
- 不使用大卡片堆叠；文档项使用单行列表而不是表格卡片。
- 文件树区域与阅读器之间使用可拖拽分割线。
- 文件树支持折叠/展开，并记住折叠状态。
- 阅读器默认占据更大可视面积，侧栏可一键隐藏。
- 长文件名不截断语义，始终可通过 Tooltip 查看全名。
- 深浅色模式均可使用，正文、表格、图标满足正常对比度。
- 滚动条使用细窄样式，减少视觉干扰。

---

## 8. 后续验收要点

- 上传 PDF、Word、Markdown 和图片后，均立即出现在当前知识库侧栏。
- 单击文件即可在主工作区阅读，无需打开外部应用。
- PDF 可跳转页码、搜索、缩放，并在重启后恢复上次位置。
- AI 引用点击后可在阅读器中打开对应原文和页码。
- 用户可选择另存为原文副本，不影响知识库内原件。
- Markdown 可在应用内编辑并保存，保存后可选择重新处理。
- 侧栏切换知识库、分组、搜索和右键操作不阻塞主阅读区域。
